Em meia hora você entende o que é CLite, como o repositório está organizado, como o board e os milestones contam a história do projeto e como você aprende enquanto implementa. A jornada é uma checklist: marque cada passo, anote o que não bater e feche com uma decisão — qual ticket você pega agora.

Antes de começar

Promessa de tempo: 30 minutos para conhecer o projeto, não para implementar. Se um passo abrir uma dúvida grande, anote e siga; a etapa 6 diz onde investigar.
  • Tenha o repositório aberto no editor e um terminal na raiz.
  • Pré-requisitos: Git e uv. O uv instala e gerencia o Python 3.12; o interpretador não tem dependências de runtime.
  • Marque os passos e escreva anotações: tudo fica salvo neste navegador (localStorage).
  • Links de documento abrem o Markdown renderizado no GitHub; links de board abrem o Projects oficial.
